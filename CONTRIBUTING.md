# Contributing to Creative Starter Dashboard Kit

Thank you for contributing to the **Creative Starter Dashboard Kit**!

## Pull Request Guidelines

1. Fork the repository and create your feature branch from `main`.
2. Ensure all Pest PHP tests pass cleanly:
   ```bash
   php artisan test --compact
   ```
3. Ensure TypeScript type checks pass:
   ```bash
   npm run types:check
   ```
4. Verify both **English (LTR)** and **Arabic (RTL)** translations and layout directions remain fully aligned.
5. Submit a pull request detailing your changes.

## Bug Reports & Feature Requests

Please use our GitHub Issue templates when submitting bug reports or feature requests.
